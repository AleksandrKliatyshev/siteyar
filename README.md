# SiteYar - Сайт-визитка

Современный сайт на Next.js с поддержкой кириллицы и SEO-оптимизацией.

## Начало работы

Запустите разработку:

```bash
npm run dev
# или
yarn dev
# или
pnpm dev
# или
bun dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

Редактируйте страницу `src/app/page.tsx`. Страница обновляется автоматически.

## Технологии

- **Next.js 14** - React фреймворк
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **SEO-ready** - готов к продвижению

## Деплой

Легко развернуть на [Vercel](https://vercel.com) - платформе создателей Next.js.
